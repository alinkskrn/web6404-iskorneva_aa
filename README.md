# Лабораторная работа № 3: Основы JavaScript
Задание: Разработать набор функций на языке JavaScript, реализующих заданный функционал.

В рамках лабораторной работы были реализованы следующие функции:
- isInteger(n) – проверка числа на целочисленность с использованием побитового оператора
- even() – генерация массива четных чисел от 2 до 20
- sumTo(n) – вычисление суммы чисел от 1 до n с использованием цикла
- recSumTo(n) – вычисление суммы чисел от 1 до n с использованием рекурсии.
- factorial(n) – вычисление факториала числа
- isBinary(n) – проверка, является ли число степенью двойки
- fibonacci(n) – нахождение n-го числа Фибоначчи
- getOperationFn(initialValue, operatorFn) – функция, принимающая начальное значение и функцию операции и возвращающая функцию, выполняющую эту операцию
- sequence(start, step) – создание независимых генераторов арифметической последовательности
- deepEqual(firstObject, secondObject) – функция сравнения объектов
